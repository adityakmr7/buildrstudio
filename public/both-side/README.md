# BothSide web assets

Derived from the BothSide 1.0.0 App Store marketing kit on November 9, 2026.
Camera, teleprompter and split images are native SwiftUI renders with fictional generated sample camera imagery. No user recordings are included. WebP images are resized for this site; social.jpg is 1200×630. icon.png derives from the current app icon, not the optional neutral proposal. The source kit remains in the duel-cam repository under Marketing/AppStore/1.0.0 with prompt provenance and render helpers.
